- **12 nov. · Une run ne dépend plus de celles jouées avant elle : l'adversaire arrive vraiment frais, un joueur signé entre remis à zéro** — trouvé en comparant deux mesures qui auraient dû être identiques (46 Coupes contre 47 sur 384 graines) : 23 runs sur 384 changeaient selon les runs jouées avant elles dans le même processus. Les joueurs d'une saison sont partagés par toutes les runs d'une session ; `fraisEtSain` ne rendait à l'adversaire que ses jambes et son infirmerie (pas sa lancée, son état du soir, sa mémoire de blessures), et un joueur signé était recopié avec ce qu'un match d'avant lui avait laissé. Les deux passent par `remettreAZero` du moteur. Après : les deux découpages rendent les mêmes 384 runs ; `check_run` garde le cas (la graine 68, la 39, puis la 68 de nouveau), vu rouge sur le code d'avant. Une run dans une page neuve ne change pas. Version 3.7.1. docs/decisions.md.
